## 📖 Overview

**PARSEdb** was developed as a core challenge during the **Le Wagon Bootcamp** to demonstrate full-stack proficiency and AI API integration. 

The application serves as a bridge between an initial idea and a fully structured database. It solves the "blank page" problem for developers by using specialized AI agents to handle the heavy lifting of schema modeling and data seeding.

---

## 🤖 Key Agents

The platform features three specialized AI personas, each focusing on a specific stage of the database lifecycle:

| Agent | Responsibility | Output |
| :--- | :--- | :--- |
| **🏗️ Database Engineer** | Analyzes project requirements and models entities, attributes, and relationships (1:N, N:N). | Optimized Data Schema |
| **📜 XML Generator** | Converts the modeled schema into the specific XML format used by Le Wagon’s visual tool. | `schema.xml` |
| **🌱 Seed Generator** | Creates realistic, idempotent Ruby code to populate the database for development. | `seeds.rb` code |

## 🚀 Learning Objectives & Features

This project serves as proof of technical expertise in several domains:

* **AI Integration:** Deep implementation of Chat APIs, managing system prompts to ensure the AI behaves as a technical specialist.
* **Full-Stack Rails:** Advanced use of Controllers and Services to handle complex AI responses.
* **Prompt Engineering:** Developing specific instructions to ensure valid XML and Ruby outputs.
* **UI/UX for Devs:** A clean, intuitive interface designed for a technical workflow.

## 🛠️ Tech Stack

* **Backend:** Ruby on Rails
* **Frontend:** HTML5, CSS3 (SCSS), JavaScript (StimulusJS)
* **Database:** PostgreSQL
* **AI:** OpenAI API (GPT-4/3.5 models)
* **External Tools:** Integration with [Kitt DB Visualizer](https://kitt.lewagon.com/db)

## 📦 How to Use

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/matheuspereirafx/parsedb.git](https://github.com/matheuspereirafx/parsedb.git)
    ```
2.  **Install dependencies:**
    ```bash
    bundle install
    yarn install
    ```
3.  **Set up your environment:**
    Add your `OPENAI_API_KEY` to your `.env` file.
4.  **Run the server:**
    ```bash
    rails s
    ```
5.  **Start Architecting:**
    Input your project idea and watch the agents build your schema and seeds.

---

## 🌐 Integration with Kitt

The XML generated by PARSEdb is 100% compatible with the **Le Wagon Database Visualizer**. Simply copy the generated code, import it into Kitt, and visualize your ERD (Entity Relationship Diagram) instantly.
